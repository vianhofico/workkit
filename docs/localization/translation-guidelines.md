# Translation Guidelines

- Brand: always write **WorkKit**.
- Prefer short, action-oriented labels suitable for mobile screens.
- Describe local/offline behavior accurately; do not imply cloud processing for on-device features.
- Preserve technical terms that users commonly recognize (PDF, OCR, QR, URL, JPEG, PNG, WebP, EXIF).
- Keep placeholders exactly intact (`{name}`, `{count}`, etc.).
- Warnings about deletion, backup encryption and destructive restore behavior must remain explicit.
- Accessibility labels and tooltips are user-facing and must be translated.
- UI locale is independent from OCR model selection.
