# WorkKit MVP Scope

## V1 must-have

- Document library
- Document scanning
- OCR
- Image to PDF
- PDF merge, split, reorder, rotate
- Signature creation and PDF signing
- QR scan and generation
- Basic image compression, resize, convert
- Local backup and restore

## Explicitly out of V1

- User accounts
- Team collaboration
- Subscription billing
- Mandatory cloud AI
- Meeting transcription
- Web admin
